# Access integration tests

ACC (permissions and access): `api` cases of the [test catalog](../../../docs/testing/test-catalog.md); classes tagged `[Trait("Area", "access")]`.
Collections (`AccessCollections.cs`): `access` to `access-4`, run in parallel; put a new class in one of them, or add
`access-5` when they get slow.
How to write them: [docs/testing/README.md](../../../docs/testing/README.md#integration-tests-testsclinichubintegrationtests).
