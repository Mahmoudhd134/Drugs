# Isolation integration tests

ISO (clinic isolation): `api` cases of the [test catalog](../../../docs/testing/test-catalog.md); classes tagged `[Trait("Area", "isolation")]`.
Collections (`IsolationCollections.cs`): `isolation` to `isolation-3`, run in parallel; put a new class in one of
them, or add `isolation-4` when they get slow.
How to write them: [docs/testing/README.md](../../../docs/testing/README.md#integration-tests-testsclinichubintegrationtests).
