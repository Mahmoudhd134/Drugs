# Known bugs: e2e track (M1.6.8, stage 1: AUTH, ACC, ISO, ERR, ADM journeys)

Found by the Playwright specs (`ClinicHub.Web/e2e`); to be folded into [known-bugs.md](known-bugs.md). Each one has a
`test.fixme("BUG-<id>: …")` naming the cases it proves. The axe findings (BUG-500 to BUG-502, BUG-505, BUG-506) are also let through by
the page checks of every other test (`e2e/support/checks.ts`, `KNOWN_AXE`) so the rest of each scan still guards the
pages; fixing one = drop its `KNOWN_AXE` entry and its `fixme`.
