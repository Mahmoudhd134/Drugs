## 1. Backend

### 1.1 `GET /drugs/tree` (D7, D8)

| Piece | Contract |
|---|---|
| Route | `GET /api/v1/drugs/tree?search=&source=` → `DrugsController.GetTree(string search = "", string source = "")`, policy ClinicContext, permission `drugs.list` (no `drugs.list` → 403 `forbidden`, CAT-048; a platform token → 403, ACC-034) |
| Query | `Catalog/Drugs/Queries/GetDrugTree/GetDrugTreeQuery(string Search, string Source) : IQuery<DrugTreeDto>` |
| Validator | `GetDrugTreeQueryValidator`: `Source` must pass `DrugSource.IsValid` → 400 `invalidRequest` (field `source`), as `GET /drugs` (CAT-091) |
| Handler | `GetDrugTreeQueryHandler(IAppDbContext db)` (**stub**, track `api`): `DrugQueries.ListedAsync(db, new DrugListFilter(search, source, null, null), cancellationToken)` (the one composition: visible + not withdrawn + source + search incl. category names), then **one** aggregate query `GroupBy(d => new { d.CategoryId, d.SubCategoryId }).Select(g => new { g.Key…, Count = g.Count() })`; joined in memory with `Categories` / `SubCategories` (≤ ~205 rows, untracked); `PinnedLast` = `CategoryIds.IsPinnedLast(id)` / `SubCategoryIds.IsPinnedLast(id)`; the bucket (null subcategory) has `PinnedLast = false` and null names |
| DTOs | `Queries/GetDrugTree/DrugTreeDto.cs`: `DrugTreeDto(List<DrugTreeCategoryDto> Categories)`; `DrugTreeCategoryDto(int Id, string NameEn, string NameAr, bool PinnedLast, int Count, List<DrugTreeSubCategoryDto> SubCategories)`; `DrugTreeSubCategoryDto(int? Id, string NameEn, string NameAr, bool PinnedLast, int Count)` |
| Answer | Only rows with `Count > 0` (without a search too: CAT-084). Categories by `Id`; their subcategories by `Id`, the bucket last. `Category.Count` = the sum of its subcategories' counts. No search match → `{ "categories": [] }` (CAT-083). JSON camelCase: `{ categories: [{ id, nameEn, nameAr, pinnedLast, count, subCategories: [{ id \| null, nameEn \| null, nameAr \| null, pinnedLast, count }] }] }` |
| Invariant | For any search and source, a bucket's `count` = `GET /drugs?categoryId=&subCategoryId=<id>\|none` (same search and source) `totalCount`, and the sum over categories = `GET /drugs` `totalCount` (CAT-081, CAT-089): both go through `ListedAsync` |

Errors: none new. `drugs.list` missing → 403 (existing `HasPermission`). Isolation: the clinic query filter (B's own
drugs never counted in A, CAT-085, CAT-088); withdrawn drugs never counted (CAT-087, CAT-146).

### 1.2 Performance measure (CAT-093, CAT-094)

Budget (D7): < 100 ms per tree or list request, warm, median of 20 requests on the dev machine. Measured by an
integration test (track `tests-api`, `Catalog/Tree/TreePerformanceTests`), which **reports and never fails on time**: it
writes `artifacts/performance/m1.7c-tree.md` (one row per request: route, query, median, p90, max, ms) for
`GET /drugs/tree` and `GET /drugs` with no search, "a" and «ا» (page 1 and the last page), on the loaded catalog
(CAT-093) and on a clinic with 5,000 own drugs added (CAT-094; insert them through the app's `DbContext` in that clinic's
scope, so the interceptor fills the search columns). The T6 ready report quotes the numbers. If the budget fails, the
session reports it to the orchestrator (design D7: the fix is decided with the user); it is not fixed in M1.7c.

### 3.3 Tree structure, accessible names and behavior

Top to bottom inside the component:

1. **Search** (`SearchField`): placeholder `drugTree.searchPlaceholder`; debounced like the pickers
   (`useDebouncedValue`), trimmed; a term of only spaces or tatweel = no search (CAT-125). **Esc** clears it and is
   stopped there (`preventDefault` + `stopPropagation`: no dialog closes, the editor's leave guard isn't triggered,
   CAT-106). **↓** moves the focus to the tree's active row.
2. **Source toggle**: MUI `ToggleButtonGroup` `exclusive`, `size="small"`, `aria-label` = `drugs.source.label`,
   buttons `drugs.source.all` / `shared` / `own` (value `all|shared|own`, never deselected to null). A change resets the
   tree like a new search (CAT-115, CAT-116).
3. **Total**: `common.results` («النتائج: N», N = `treeTotal`, grouped digits) once a tree with ≥ 1 category is shown.
4. **Thin progress bar** (`LinearProgress`, `aria-label` `common.loading`) while a new search or source loads over the
   old tree (`isPlaceholderData`), as `SearchableList` (CAT-101, UX-035).
5. **Scroll panel**: `Box` with `maxHeight` and `overflowY: "auto"`; the `IntersectionObserver` root of every bucket
   (CAT-118); the page scrolls past it.
6. **Tree**: `role="tree"`, `aria-label` = `drugTree.label`.
   - **Category row**: `role="treeitem"`, `aria-level={1}`, `aria-expanded`, `aria-label` = `drugTree.nodeLabel`
     `{name: categoryName(category, language), count}` («العيون، 541»); content: a chevron `IconButton` (`tabIndex={-1}`,
     `aria-label` + `Tooltip` = `drugTree.open` / `drugTree.close` `{name}`, UX-042; closed: points the reading direction,
     `ChevronRight` in LTR / `ChevronLeft` in RTL; open: `ExpandMore`), the name (wraps, `overflowWrap: "anywhere"`), the
     count (grouped digits) at the line's end (or wrapped below at 375 px). Its children: `role="group"`.
   - **Subcategory row**: the same at `aria-level={2}`; the bucket's name is `drugs.noSubCategory`. Its `role="group"`
     has `aria-busy="true"` while one of its pages loads (CAT-107).
   - **Drug row**: `role="treeitem"`, `aria-level={3}`, `aria-label` = the drug's name; content: the name (wraps
     anywhere, never an Arabic name); the active ingredients on one line (`noWrap` + ellipsis, the full text in a
     `TapTooltip`; at < `sm` it wraps anywhere instead; no line when null, CAT-112, CAT-002); own drugs only: their dosing
     sentence (`DrugText`'s dosing, I18N-009); the chip `drugs.chip.shared` or `drugs.chip.own`; `common.added` chip when
     in `selectedIds` (else the ⊕ icon, as the picker). **No description** (DRUG-059, DRUG-103).
   - After a bucket's last loaded drug: a sentinel element `<div data-testid="drug-tree-sentinel"/>` inside that
     bucket's `role="group"` (observed; root = the scroll panel; tests pick a bucket's sentinel through its group); while the next page loads
     a `CircularProgress` (`aria-label` `common.loading`); while more pages exist and none is loading a `Button`
     `common.loadMore` (reachable by Tab, CAT-108); a failed page: `Alert` `common.loadFailed` + `Button` `common.retry`
     inside that bucket only (CAT-109).
7. **States instead of the tree**: first load → `CircularProgress` (`aria-label` `common.loading`); tree request failed
   → `Alert` `common.loadFailed` + `common.retry`; no category in the answer → `drugs.noOwnDrugs` when source is "own"
   and there is no search (CAT-111), else `drugs.noResults` (CAT-110, CAT-073).

Behavior:
- **Open/close**: a click on a category or subcategory row (or its chevron) toggles it; opening a category shows all its
  subcategories with counts from the loaded answer (no request, CAT-096, CAT-120); opening a subcategory starts its
  `useDrugBucket` (several may be open, each its own query, CAT-120); closing drops its pages (§ 2.2). A click whose
  `event.detail > 1` is ignored (a double click opens once, adds once: CAT-123, RX-012, GRP-054).
- **Infinite scroll**: when a bucket's sentinel enters the panel's view and `hasNextPage && !isFetchingNextPage`, fetch
  the next page once (CAT-097, CAT-119; exactly 30 → no second request, CAT-098). Rows are `dedupeById` (CAT-122).
- **Keyboard** (`treeKeyAction`): roving `tabIndex` (the active row 0, the others -1); the first row is the active one
  from the start and after each new tree. Next/previous stop at the edges (UX-018); ↓ on the last loaded drug of a
  bucket with more pages fetches the next page and moves the focus to its first new drug (never to `<body>`, CAT-104);
  Enter on a drug calls `onSelect` and keeps the focus on that row (CAT-105). RTL mirrors the arrows (CAT-103).
- **Auto-open** (D7): once per (search, source) change, on its first answer (a refetch of the same key, e.g. after a
  drug save invalidates `drugKeys.all`, never opens or closes anything, C12), `autoOpenBucket` opens its category and bucket,
  unless the user closed that bucket for the same search and source (it stays closed until they change, CAT-100).
- **New search or source**: the old tree stays with the progress bar; when its first answer arrives everything closes
  (open sets reset, bucket queries removed), then auto-open applies (CAT-101, CAT-116).
- **Selecting a drug** keeps the search, the open nodes, the loaded pages and the scroll position (CAT-117; DRUG-060
  retired).
- **Language switch**: names change and re-sort (`sortTree` on render), open nodes stay, nothing is refetched (CAT-126).
- **Clinic switch**: the query cache is cleared by the existing context switch (ISO-040); nothing of A shows in B
  (CAT-129).

  then `drugs.noSubCategory`; changing the category resets it, CAT-133). Categories from `useDrugCategories`
  (`enabled` with `drugs.list`).

- **Saving an own drug** (create) while the toggle is «المشتركة» switches it to «أدوية العيادة», clears the search, page 1 (CAT-137, C35).
- A slower, older list answer never overwrites a newer one (React Query keys include the filters; CAT-144).
