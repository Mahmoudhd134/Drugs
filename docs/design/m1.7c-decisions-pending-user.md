# M1.7c decisions pending the user's review

The user was away during M1.7 and pre-approved its gates (2026-10-22). The M1.7c T0 contract
([m1.7c-contract.md](m1.7c-contract.md)) logs here every point the design, the business file and the test cases didn't
settle, decided in the design's spirit and kept minimal. One line per decision; the contract cites them as C1…; later
phases (T1–T6) append theirs.
