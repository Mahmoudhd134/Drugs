## How this file is organised

1. A new area **CAT — Shared catalog and categories**: everything new, numbered from CAT-001 by section.
2. **New cases in existing areas**, at each area's next free ID (ISO-044, ACC-084, ADM-292, DRUG-105, GRP-099, RX-107,
   I18N-024, UX-038).
3. **Changed existing cases**: every existing case whose text, expected result or setup changes (the rename and the
   behavior changes), per area; retired cases; cases whose test data changes only; catalog text outside the cases.

Test data: `load_catalog.py` loads the full catalog into every test database (run by the harness and the e2e setup, design D12); its baseline (23,414 shared drugs, none
withdrawn; 23 categories, 182 subcategories) is read from the harness (the load itself is checked once by hand, D11; no case tests it). Real shared drugs used below (looked up by exact name): "ALEMOX 1 GM 12 F.C.TABS."
(«أليموكس», AMOXICILLIN, «مضادات العدوى › البنسلينات»), "VIGAMOX 0.5% EYE DROPS 5 ML" (MOXIFLOXACIN, «العيون › مضادات
العدوى للعين»), "TOBRADEX EYE SUSP. DROPS 5 ML" and "TOBRADEX EYE OINT. 3.5 GM" («العيون › مضادات الالتهاب
للعين»), "XALATAN 50MCG/ML EYE DROPS 2.5 ML" («العيون › المياه الزرقاء»), "NAILNER NAIL FUNGUS PEN 4 ML" (no ingredients).
No Arabic drug name is ever exposed (screens, admin, API); «أليموكس» (ALEMOX's hidden Arabic name) is used only as a search term. "Withdrawn"
(code) is shown to users as «معطّل من الإدارة» / "Disabled by admin", with a tooltip on every mark (design D6). Clinics A and B; A's own drugs "Tobradex" (in «العيون › مضادات الالتهاب للعين») and «قطرة مرطبة»;
protocol "Post cataract" (P). Own drugs get «العيون › المياه الزرقاء» unless a case says otherwise. Tests that create,
edit, withdraw, restore or delete shared drugs, categories or subcategories use **their own** rows (`Data.SharedDrug()`,
`Data.Category()`, `Data.SubCategory()`), never imported ones, so a normal run never trips the baseline check. Migration
cases run in the migration collection, on copies of the bare template (migrated, no catalog; D12).
